# Benchmark Results (2026-03-18)

Mini Redis vs Redis vs MySQL 비교 부하 테스트 결과 요약.

## 1) Test Environment

- Date: 2026-03-18
- Host: local macOS (Apple Silicon)
- Tools:
  - `redis-benchmark 8.6.1`
  - `redis-server 8.6.1` (comparison target)
  - `mysqlslap 8.3.0`
- Targets:
  - Mini Redis: `127.0.0.1:6379`
  - Redis OSS: `127.0.0.1:6380` (temporary local instance)
  - MySQL: `127.0.0.1:3306` (not running in this environment)

## 2) Benchmark Commands

Common options:

- `-n 20000`
- `-c 50`
- output: `--csv`

Commands:

- `PING_MBULK`
- `SET`
- `GET`
- `DEL key:__rand_int__`

Notes:

- Mini Redis parser currently supports RESP Array of Bulk Strings only.
- `PING_INLINE` and `INFO` are not supported in Mini Redis (`ERR protocol error`, `ERR unknown command`).

## 4) MySQL Benchmark Status

MySQL benchmark was attempted with `mysqlslap`, but this environment has no running MySQL server on `127.0.0.1:3306`.

Observed errors:

- `Can't connect to MySQL server on '127.0.0.1:3306' (1)`
- `mysqlslap: Error when connecting to server`

## 6) Re-run Commands

Mini Redis:

```bash
redis-benchmark -h 127.0.0.1 -p 6379 -n 20000 -c 50 --csv -t ping_mbulk
redis-benchmark -h 127.0.0.1 -p 6379 -n 20000 -c 50 --csv -t set
redis-benchmark -h 127.0.0.1 -p 6379 -n 20000 -c 50 --csv -t get
redis-benchmark -h 127.0.0.1 -p 6379 -n 20000 -c 50 --csv DEL key:__rand_int__
```

Redis OSS:

```bash
redis-server --port 6380 --bind 127.0.0.1 --save "" --appendonly no --daemonize yes
redis-benchmark -h 127.0.0.1 -p 6380 -n 20000 -c 50 --csv -t ping_mbulk
redis-benchmark -h 127.0.0.1 -p 6380 -n 20000 -c 50 --csv -t set
redis-benchmark -h 127.0.0.1 -p 6380 -n 20000 -c 50 --csv -t get
redis-benchmark -h 127.0.0.1 -p 6380 -n 20000 -c 50 --csv DEL key:__rand_int__
redis-cli -h 127.0.0.1 -p 6380 shutdown nosave
```

MySQL (requires running server):

```bash
mysqladmin ping -h127.0.0.1 -uroot --connect-timeout=2
mysqlslap --host=127.0.0.1 --port=3306 --user=root \
  --concurrency=10 --iterations=1 --number-of-queries=10000 \
  --create-schema=bench --query="SELECT value FROM kv WHERE id=1"
```
