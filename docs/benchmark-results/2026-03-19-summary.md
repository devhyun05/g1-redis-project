# Benchmark Results (2026-03-19, EC2)

3-way benchmark comparison run on EC2 (`43.201.48.238`) with:

- Mini Redis (project server): `127.0.0.1:6379`
- Redis OSS (temporary comparison container): `127.0.0.1:6380`
- MySQL (container): `127.0.0.1:3306`

Common load profile:

- Total requests/queries: `20000`
- Concurrency: `50`

## 1) Redis-family Results (`redis-benchmark`)

| Command | Mini Redis RPS | Redis RPS | Mini/Redis | Mini P95 (ms) | Redis P95 (ms) |
|---|---:|---:|---:|---:|---:|
| PING_MBULK | 12,515.64 | 64,102.56 | 19.52% | 5.447 | 1.207 |
| SET | 9,876.54 | 68,259.38 | 14.47% | 6.591 | 1.175 |
| GET | 11,481.06 | 69,930.07 | 16.42% | 6.023 | 1.255 |
| DEL | 12,180.27 | 68,965.52 | 17.66% | 5.991 | 1.295 |

## 2) MySQL Results (`mysqlslap`)

`mysqlslap` output is time-based (no p95/p99), so RPS is derived as:

- `RPS = 20000 / average_seconds`

| Query | Avg Seconds | Derived RPS |
|---|---:|---:|
| GET (`SELECT v FROM kv WHERE k='user'`) | 2.378 | 8,410.43 |
| SET (`INSERT ... ON DUPLICATE KEY UPDATE`) | 3.391 | 5,897.97 |
| DEL (`DELETE FROM kv WHERE k='user'`) | 2.263 | 8,837.83 |
